# 📊 Customer Analysis using Tableau

An interactive Tableau dashboard that analyses customer purchasing behaviour, sales performance, and revenue trends to help businesses make data-driven decisions. The project transforms raw sales data into meaningful visual insights for customer segmentation, revenue analysis, and business strategy.

---

## 📌 Project Overview

Customer analysis enables businesses to understand customer behaviour, identify profitable segments, and improve decision-making. This Tableau dashboard provides interactive visualizations that highlight revenue distribution, customer demographics, purchasing patterns, and discount impact.

The project demonstrates the complete analytics workflow, including:

- Data Collection
- Data Cleaning
- Data Preparation
- Data Visualization
- Business Insights

---

## 📂 Dataset

The project uses customer sales data containing information such as:

- Customer Demographics
- State
- Region
- Product Category
- Sales Revenue
- Quantity Sold
- Discount Percentage
- Order Date

Dataset File:
- `sales_06_FY2020-21.csv`

## 📈 Dashboard Features

The dashboard includes the following visualizations:

### Revenue Analysis
- Revenue by State
- Revenue by Month
- Revenue by Region
- Revenue by Product Category

### Customer Analysis
- Revenue by Age Group
- Revenue by Gender
- Customer Segmentation

### Sales Insights
- Quantity vs Discount Correlation
- Regional Revenue Contribution
- Category-wise Performance

---

## 📊 Key Business Insights

- Identify high-performing states and regions.
- Understand monthly sales trends and seasonality.
- Analyse customer demographics contributing to revenue.
- Evaluate the relationship between discounts and purchase quantity.
- Discover top-performing product categories.
- Support strategic business decisions using visual analytics.
